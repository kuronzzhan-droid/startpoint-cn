# 星见镇的摇曳 · 六人演出 V7

本目录交付池 `990006` 的待接入美术、独立技能演示场景和离线预览。13 页由一张封面、六张人物海报及六段主动技能演示组成，另附选池横幅。没有修改生效卡池配置、manifest、资源版本或服务端代码；合并本目录不会启用资源。

## 先看预览

在仓库根目录执行（Node.js 内置模块，无需 npm 安装）：

```sh
node assets/asset-patch/artwork/starview-sway-v7/preview/build.cjs assets/asset-patch/artwork/starview-sway-v7/starview-sway-preview.html
```

用浏览器打开生成的 `starview-sway-preview.html`。页面可完全离线播放、逐帧查看、半速播放和连续播放完整演出。取用游戏原生资源时，将资源包解压到一个离线目录：

```sh
python -m zipfile -e assets/asset-patch/artwork/starview-sway-v7/native-assets.zip ./starview-sway-native
```

## 交付内容

- `native-assets.zip` 与 `native-resources.json`：7 套原生 Movie（每套 Movie、timeline、atlas、PNG）及 1 张选池横幅，共 29 份资源。原生字节保存在待接入 ZIP；仓库为这个固定路径设置了 20 MiB 上限，清单逐项核对 29 个成员。公开 fork 无法接收新的 LFS 对象，因此此包不使用 LFS。
- `scenes/`：六人独立 terrain、战斗回放和五张主表的新增行。独立场景避免覆盖其他池共用的官方场地。
- `feature/`：仅针对 `990006` 的演出页配置及字段说明。
- `config/pool-990006.baseline.json`：作者测试分支中的原池单行快照，用于核对原规则，不可作为整张配置覆盖。
- `preview/`：结构化 Movie 数据、六段实际原生录像、播放器和便携 HTML 生成器。

## 验证与接入边界

```sh
node assets/asset-patch/artwork/starview-sway-v7/preview/build.cjs --verify
python assets/asset-patch/artwork/starview-sway-v7/verify.py
```

预览重建须匹配冻结 HTML 的 SHA-256，细节见 [预览说明](preview/README.md)。`verify.py` 检查交付文件身份、压缩资源、六人场景引用、页面顺序和原池快照。文件缺失、资源包成员变化或合同变化会失败。Python 校验器要求 Python 3.9 或更高版本。

已有离线证据覆盖六人原生录制、完整界面中的位置和 13 页连续演出；不代表 Android/iOS 真机或作者当前完整资源链已验收。新独立场景仅奈芙提姆关卡 928 完成桌面复录，其余五条通过静态读回。原生回放基于 C8601，网页录像按原生 1080×1920 舞台、`(0,60,1080,1560)` 技能视口展示。少量边缘特效、条形信息可能与界面重叠；原生此类演示为静音，无完整立绘 cut-in。

后续接入须由作者对实际目标分支处理：

1. 重新核对原池合同、实际有效表和资源链。`main` 的场景空位核对与 `test-server` 的卡池快照分开记录，不能作为同一终端基线。
2. 按 `feature/`、`scenes/MASTER-ROWS.json` 合并指定行，保留其他池及完整表的原有键与顺序。候选 Quest ID `923–928` 不代表已预留，若发生冲突须同步修改所有相关引用。
3. 将资源按清单的逻辑名加入正式增量；按仓库既有资源地址算法封包，核对 iOS 资源配对、图集预算、专用券图标和实际 UI。不要把本目录或主表片段直接作为生效 CDN 包。
4. 在实际客户端验证切页、技能播放与下方按钮遮挡后，再登记资源版本及 manifest。

回退本次离线交付只需撤回该目录、卫生脚本中的对应固定路径例外及配套回归测试和 CI 接线；无在线配置或存档迁移。
