# 1.4.347 光暗龙合击切属性去掉觉醒门

接在 1.4.346 后面，单个补丁包，只改 ability 表。纯数据，热加载，服务端和 APK 都不用改。

## 光龙 拉夫马诺 151159 / 暗龙 阿鲁玛德乌斯 261089
能力1「自身站合击位、且主位为暗/光属性时，自身视为暗/光属性」（1511591#2、2610891#6）：c3=1,c4=1 改为 c3=0,c4=空，与官方蕾薇 1612011#1 相同。

原因：这两行只在觉醒等级=1 时生效，而联机战斗里角色的觉醒等级没有生效，行被过滤。实测（1008092 + 1.4.345，同 boss 同编队）：单人切属性、技能显示 ++；联机不切、技能显示 +。

影响：这条能力不再要求觉醒，未觉醒的龙也会切。只有站合击位的龙会切，主位的龙始终是原属性。

未解决：联机时觉醒内容可能整体失效，全表有 165 行带同样的觉醒1门槛，涉及 45 个角色。
