# 角色平衡改动 1.4.230：麻痹・气绝／追击写法修正＋队长前置效果移到队长技

只改面板文字（custom_ability_string），数据、数值、服务端都不动。底稿 1.4.229。

## 1. 麻痹・气绝与追击
- 官方口径：对「麻痹・气绝」状态敌人的加成（kind 118，客户端状态名 ability_description_condition_target_paralysis＝「麻痹・气绝效果」）属**独立伤害乘区2**；追击伤害（kind 53）属**乘区3**，只在目标虚弱（气绝槽打满的Down）或畏缩中生效。
- 文案：对麻痹的 2 处照游戏内官方原文写成「对麻痹·气绝效果中的敌人造成的伤害」；7 处「追击伤害」注明「（对虚弱中的敌人）」；Sec-2600Li「眩晕积蓄」统一为「使敌人进入Down效果的容易程度」。
- 数据问题（未改，待作者定）：瑞西塔尔能力4、tweyen_light 能力4 设计稿的「气绝」做成了追击伤害（kind 53）那一行；按官方口径「气绝」已被麻痹那行（kind 118）覆盖，这行实际给的是追击加成。

## 2. 队长前置效果写回队长技
- 数据放在能力里但带「队长」前置的效果，面板文字从能力移到队长技（去掉「担任队长时」），共 26 行；数据行不动，行为不变。能力只剩这类效果的（泽赫尔能力2）写「效果写在队长技中」。
- 没动：米娅、西蒙、特克托这几处能力是客户端自动生成文字（没有覆盖文案）。
