# 角色平衡改动 1.4.227：MOD 角色面板文案与技能描述规范化

只改玩家看到的文字，数值、条件、效果一个没动。不需要新 APK。

## 改了什么
- 108 个 MOD 角色（自制 + 改过的官方角色）全部过了一遍：先由 6.1 Sol 对照数据和技能 DSL 查漏写、写错、对不上（82 处），再按《面板文案规范》（同目录 面板文案规范.md）重写，第二轮逐条对照数据审校定稿。
- 客户端表：custom_ability_string 433 键（能力/队长覆盖文案、技能强化行、专属强化弹射说明、追加技能说明）、action_skill 102 个技能的描述、character_text 对应技能描述列。
- 服务端：assets/cdndata/character_text.json 64 个角色的技能描述列（抽卡特性页用），与游戏内 action_skill 保持一致。

## 规范要点
- 一行一条；条件前缀顺序：主位图标 → 属性共鸣 → 状态/模式 → 触发；同条件同对象的效果合成一句。
- 术语统一：强化弹射、直接攻击、Fever、贯穿效果、队伍全体、技能槽最大值、追击伤害。数值一律半角「+X%」。
- 9 个独立伤害乘区一律标「（独立伤害乘区N）」，其余不标。
- 技能描述照官方：不写伤害倍率和段数，buff 写「X提升效果」，条件分支用【】，伤害改判写「（伤害量以X伤害判定）」。
- 自创机制定了固定说法：多重强化弹射「同时发动A型与B型」、强化弹射Lv4、形态切换、杰拉德当前生命值比例伤害与斩杀等。

## 刻意没动的
- 官方角色里技能 DSL 没改过的技能描述、官方原有的说明串：保持官方原文（17 处，含 rec_android_1anv、resistance_princess、darkness_dragon 档1/2 等）。
- 数据问题另报，不在本包：瑞西塔尔技能 DSL 只剩演出（1.4.228 热修）；月满稻穗能力4 的「月满丰穰」强化前后数据相同（待作者定）。
