# 热修 1.4.278：诺瓦 / 蕾薇 乘区副本「null 角色」不生效

- 补丁：`pinball-1.4.277-1.4.278-1-nova-levi-zones-fix-local.zip`，sha256 `02e5814e91a3d41cfc0daecba70399a98a04e0ea4557bd70c0cad60f89fbf063`，2 个成员（ability、leader_ability 按键合并），接在 1.4.277 后，热加载。
- 服务端：不用改；不用重新发放角色。

## 问题

1.4.277 的 22 个副本把「全队 / 去掉属性限制」的角色组写成了空串，客户端显示为「null 角色」，相关加成全部不发动（测试员 10-24 反馈）。

## 修复

- 22 人中 95 个能力 / 队长技键、105 行、111 个角色组字段由空串改为 `(None)`（全部角色）；其余列不动，原版诺瓦、蕾薇不动。
- 构建器新增门禁：被读取的角色组列不得为空串，面板与描述不得出现 null。

## 说明

- 「因第 3 位主要角色非光属性角色而无法发动」不是缺陷：蕾薇原版「搭配光属性主位当合击时视为光属性」，光版与共鸣版照抄该条件。
- 1.4.277 的已知问题不变。均未真机验证。
