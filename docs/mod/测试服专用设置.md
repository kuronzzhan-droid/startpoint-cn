# 测试服专用设置（不要带上正式服）

本仓库 main 与测试服完全一致，其中下面这些只为测试服服务。正式服拉取时请按本页逐项排除或关闭。

## 一、代码里的测试服专用改动

这 5 个文件的改动单独放在 [kulo-patches/02-test-server-only.patch](kulo-patches/02-test-server-only.patch)，正式服**不要应用**：

| 文件 | 作用 | 正式服风险 |
|---|---|---|
| `src/lib/player-login.ts` | 未知账号名 + 共享测试密码 = 自动建号并复制满号模板（`TEST_SERVER_SHARED_PASSWORD`、`TEST_SERVER_TEMPLATE_SAVE`） | 设了变量就会给任何人发满号 |
| `src/lib/quest/finish/single-finish-transaction.ts` | 单人领主战 / 世界剧情 boss 的**记录分**按 `SINGLE_SCORE_SCALE` 缩放 | **不设变量时默认 0.5**，正式服单人记录分会减半 |
| `src/multi/tcp/lobby.ts` | 人机补位复制房主当前队伍（`NPC_COPY_HOST_PARTY`） | 默认关；开了人机强度跟房主走 |
| `src/routes/cn/asset.ts` | 补丁分流下载：`LOCAL_PATCH_AFTER` 之后的包从本机下发（`LOCAL_PATCH_BASE_URL`、`LOCAL_PATCH_FILES`） | 默认关；正式服走自己的 CDN |
| `src/lib/client-admission.ts` | `[ADMISSION-DIAG]` 诊断日志（只记 build、IP、拒绝原因，不记密钥） | 只是多打日志 |

其余服务端改动（结算回执、超限 Lv120、进程守卫、/load 写事务、实时联机子进程自动重建等）在 [kulo-patches/01-server-fixes-and-features.patch](kulo-patches/01-server-fixes-and-features.patch)，正式服可以用。

## 二、测试服 `.env` 里的值（仓库里没有 .env，这里只列名字和用途）

| 变量 | 测试服取值 | 说明 |
|---|---|---|
| `SINGLE_SCORE_SCALE` | 0.01 | 测试服专用；正式服如果带了上面的代码，务必显式设成 `1` |
| `NPC_COPY_HOST_PARTY` | 1 | 测试服专用 |
| `TEST_SERVER_SHARED_PASSWORD` / `TEST_SERVER_TEMPLATE_SAVE` | （保密） | 测试服专用，正式服不要设 |
| `CDN_BASE_URL` / `LOCAL_PATCH_BASE_URL` / `LOCAL_PATCH_AFTER` / `LOCAL_PATCH_FILES` | 测试服地址 | 测试服专用 |
| `MULTI_AI_FILL_TIMEOUT_MS` | 0 | 测试服让人机立刻补位，正式服按需 |
| `MULTI_BATTLE_RELAY_PROCESS` | 1 | 联机中继子进程，正式服可用 |
| `SQLITE_SYNCHRONOUS` / `SQLITE_DIAGNOSTICS` / `CN_LOAD_HTTP_COMPRESSION` | NORMAL / true / gzip | 性能相关，正式服可按需 |

准入（client-admission）配置、管理密码、测试员密钥都只在服务器上，不在仓库里。

## 三、补丁链

- `assets/asset-patch/manifest.json` 里标了 `local_test_only: true` 的条目是测试服先行内容。正式服采纳前请确认已在测试服验过。
- 1.4.220 是与正式服对齐的空版本边（0 成员）。以后测试服从 1.4.221 起推，正式服采纳时沿用测试服编号，正式服版本永远不高于测试服。

## 四、客户端

- 测试包 `com.leiting.wt`（v34 / v34-x86）连的是测试服地址、用测试服准入密钥，**不公开分发**，只在测试员群发。
- APK 补丁源码在 [apk-patches/](../../apk-patches/README.md)：v17→v33 的 101 个补丁 + v34 新增 102–111（灰的 R4 六项修复、超限台座/悖论之核/双消耗框/确认文案），x86 模拟器构建脚本在 `apk-patches/_build-x86/`。
- 补丁 52「测试服 v17 身份」和 19「准入」相关的包名、地址、准入 ID 是测试服的，正式服要换成自己的。
