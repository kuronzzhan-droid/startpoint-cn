【测试服角色平衡填报格式】（整段复制到QQ，填完发给 PARADOX）

━━━━ 规则（只有5条）━━━━
1. 一个角色一段，段与段之间用一行 ==== 隔开。
2. 只写要改的项，不改的不写。
3. 数值一律写「原值→新值」；不知道原值就写「改为 X」或「×0.8」（按比例）。
4. 百分比都按满级写（能力/技能等级满时的数值，游戏里显示的那个），低等级会按比例自动跟着变。
5. 能力里有好几个效果时，用游戏描述里的原话点出是哪一句，再写数值。

━━━━ 模板 ━━━━
====
角色：（游戏内名字）　属性：（火/水/雷/风/光/暗）　ID：（知道就填，不知道留空）
理由：（一句话，可不写）
基础：HP 原→新；ATK 原→新　（Lv100 基础值，或写 HP×1.1）
技能：能量 原→新；伤害 ×系数　（进化技不同就另写一行「技能＋：…」）
队长：（哪一句）原→新
能力1：（哪一句）原→新
能力2：
能力3：
能力4：
能力5：
能力6：
新增：（要加的新效果，写「照搬 某角色 能力X 的 某句，数值 Y」）
删除：（要删的效果，点出原句）
====

━━━━ 示例 ━━━━
====
角色：水灵幽魂　属性：水　ID：129998
理由：竞速池太强
基础：ATK 2800→2500
技能：能量 260→300；伤害 ×0.85
队长：水属性角色攻击力 +80%→+60%
能力2：每层自身攻击力 60%→40%；每层自身强化弹射伤害 45%→30%；层数上限 10→8
能力4：主位开技后自身技能槽回充 50%→30%
新增：照搬 风暴恶魔拉比 能力4 的「主位时发动技能后回充」，数值 20%
删除：能力5 的「受伤时攻击力+20%」
====

━━━━ 常用词（照这些写我认得最快）━━━━
数值类型（乘区）：
　攻击力（攻击型）｜技能伤害｜强化弹射伤害（PF）｜直击伤害｜属性伤害（对X属性敌人）
　一般条件伤害（条件型）｜狂热伤害｜受到伤害减少｜HP
资源类：技能槽回充（立即+%）｜技能充能速度｜技能槽上限｜狂热槽｜强化弹射槽
状态类：贯穿｜最大速度固定｜冲刺间隔缩短｜护盾｜异常赋予/抵抗
写法附带项（有就写）：
　对象：自身 / 队伍 / 队伍X属性角色 / 队长 / 副位(协力)
　条件：主位时 / HP≥X% / 每X连击 / 发动技能后 / 强化弹射后 / 狂热中 / 每层
　时间：持续X秒，冷却X秒，层数上限X

━━━━ 改不了或有上限的（填了会被打回）━━━━
· 技能「加新效果」做不到（技能是编译好的程序）；技能只能改能量、伤害倍率、命中数值。要加的效果写成能力/队长里的「发动技能后…」。
· 新增效果只能照搬游戏里已有的同类效果（最好同属性角色），不能凭空造新机制。
· 直击计数只有 1/2/3 次，没有 4 次以上。
· 队伍充能只能按属性筛选，「全队不分属性」等同于写成「队伍X属性角色」。
· 降低别人攻击力最多 -50%（引擎下限）；技能槽上限最多 +100%。
· 角色名有重名/多个版本（泳装、节日等）时一定写属性，最好写 ID。
