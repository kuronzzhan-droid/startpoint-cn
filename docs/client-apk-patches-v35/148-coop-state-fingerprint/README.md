# 148 联机状态指纹诊断（v1 全量/差量逐帧采样）

- 首发版本：v35p / 1008015（run16）
- capability：`coop-state-fingerprint-v1`
- 依赖前置补丁：147（基于 v35o SWF 叠加）
- 对应数据边：无客户端数据表变更；配套诊断服务端解析 `wf-fp v1`（`[0,[5,{"kind":"wf-fp","v":1,...}]]`）Heartbeat 扩展消息（合同见 `<WORKDIR>/outputs/work/coop-desync-20261021/fingerprint-contract`）

## 作用

为排查多人协力战斗跨端状态分叉（desync），在协力 Socket 战斗中对本机各 `Battle` 实例采集只读状态指纹（Battle/Zone、Enemy、Trial、Funnel、Modifier/Buff、各路 Xorshift RNG 的 `randomNum`、User/Coop 输入与 Route/Speed 事件），按 initial / 每 30 帧 full 与其余帧相邻 delta 编码为 JSON，经原 `XMLSocket` Heartbeat 通道分片限速上报。

## 改动类与方法

- 在 9 个既有方法内插入只读钩子：`Battle/proceed`、`BattleDerailleur/proceed`、`BattleDerailleur/addSocketCommand`、`BattleDerailleur/_addSocketCommand`、`BattleScenePlayingStateImpl/socketInput_broadcastMessage`、`BattleConnection/send`、`BattleSocketContact/leavingSceneHandler`、`BattleSocketContact/discardSocket`、`SockletConnection/close`。
- 在 `Battle` 类追加 252 个静态诊断辅助方法（`Battle$/wfxFp*`）与静态诊断槽，不改动既有实例槽或逻辑 RNG 状态。

## 开关与数据写法

- 静态布尔总开关：`pinball.scene.battle.battle.Battle.wfxFpEnabled`（默认 `true`；可通过 `python -B build.py --candidate --disabled --replace-work` 生成默认关闭包）。
- 仅在 `BattleSceneKind.Cooperative` + `MultiBattleSceneValuesConfigKind.Socket` + 非单人/非孤立且真实 Socket 已建立时激活。
