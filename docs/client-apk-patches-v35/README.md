## 和 `client-patch/pr43-port` 的关系

- 这些补丁是在测试服 v34/v35 SWF 上逐方法改写的,P-code 是各轮最终合成方法。要进正式包,需要把对应方法加进 `pr43-port/game-plan.json` 的移植清单,按原有哈希契约重新审查,本 PR 不改 `pr43-port`。
- 没有补丁改动 `cn/admission/*` 准入类;准入常量仍按 `rotate_admission.py` 在封包后单独轮换。
- 数据侧写法(`wfx:<码>:...`、`wfx_unlock_*` 等文案表键)依赖这批补丁,旧客户端读到会忽略。

构建需要本机的 v29-coop 底包,用环境变量 `WF_BASE_APK` 指定路径。APK、SWF、签名材料和准入配置都不在仓库里。
