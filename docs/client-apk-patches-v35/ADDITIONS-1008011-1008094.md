## 打包要点

- `bundle.zip` 里还要带：★5 等级上限与经验表（超限 Lv120）、超限台座图集；改了 bundle 要同时换 `bundle.zip.sha1`。
- 出 ARM 与 x86 两份；末步跑 `apk_nocache.py`，免得玩家要清缓存。
- 出包前检查 `bundle.zip` 里的 `*_iosbundled` 表和 CDN 补丁有没有同名键（撞名会报 C7051）。
- versionCode 要大于 1008094。

各补丁的源码与构建脚本在测试服仓库的工作区里，按需再整理进本目录（格式同 112–143）。
