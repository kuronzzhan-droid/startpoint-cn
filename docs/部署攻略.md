# 从零开服到拿到八位自制/改造角色 · 保姆级攻略

照着本文从上往下做,终点是:你(和你的朋友)在自己的世界弹射物语 CN 私服里,
玩到「深渊连战」roguelike、15 把深渊武器,并领到八位自制/改造角色——
**赛瑞斯(129999)、史黛拉(139999)、杰拉德(149999)、风巨蜥(149998)、拉夫马诺(151159)、阿鲁玛德乌斯(261089)、拉芙(169998)、基诺维(169999)**。

> 更完整的技术参考(存量服升级、外血统救援、每一层增量的说明)在
> [self-host-modes.md](self-host-modes.md);本文只走"从零到能玩"的最短路径。
>
> ⚖️ 本仓库**不分发**官方基础 CDN 和客户端 APK(版权内容,自备),只提供服务端代码与自制增量。
> 仅供离线自架、单机自娱与学习。

## 0. 你需要准备什么

| # | 东西 | 用途 | 哪里来 |
|---|---|---|---|
| 1 | 一台电脑(Windows/Linux 均可),Node.js ≥ 20 + git + Python 3.10+ | 跑服务端 + 客户端补丁脚本 | nodejs.org / python.org |
| 2 | **CN 基础 CDN(~11GB)** | 游戏全部基础资源 | **自备**。官方源已停服,从 WF 私服圈/已有部署获取;须完整到官方链尾 **1.4.54**,仓库会继续桥接到 1.4.312 |
| 3 | **五合一客户端基座 APK** | 保留完整战斗/P-code 补丁,只重指向你的服 | [本仓 Release 的 `WorldFlipper-abyss-v2.apk`](https://github.com/kuronzzhan-droid/startpoint-cn/releases/tag/client-base-v2.0);下载后必须按步骤 2 核对 SHA256 |
| 4 | Python 3.10+ + Java 8 + [FFDec 26.2.1](https://github.com/jindrapetrik/jpexs-decompiler)+ Android build-tools(zipalign/apksigner)+ 一个自造 keystore | 只换服务器地址并重签 APK | FFDec 官网;keystore 用 `keytool` 自己生成 |
| 5 | 玩的设备:安卓手机或模拟器(MuMu 12 实测可用,包名 `com.leiting.wf`) | 跑重打后的客户端 | — |

[deployment.md](deployment.md) 配 nginx + HTTPS + 域名,其余步骤一样。

## 1. 起服(10 分钟)

```bash
git clone https://github.com/kuronzzhan-droid/startpoint-cn.git starpoint-cn
cd starpoint-cn          # 默认分支就是发布分支 release/modes-20260714,不用切
npm install
cp .env.example .env     # 局域网区块默认激活
bash scripts/start-cn.sh # 构建 + 启动,端口 8001(Windows 用 Git Bash;或 npm run debug:cn 热重载)
```

客户端在**另一台设备**(手机/模拟器)上玩时,编辑 `.env`:

- `CN_LISTEN_HOST` = 你的内网 IP(如 `192.168.1.10`)
- `CDN_BASE_URL` = `http://你的内网IP:8001/patch/cn`
- 监听非本机地址时须配管理令牌:`CN_ADMIN_TOKEN`(用 `scripts/generate-admin-token.ps1` 生成)

**放基础 CDN**:把你自备的 CN CDN 放到仓库根的 `.cdn/cn/`(结构与校验见
[cdn/overview.md](cdn/overview.md))。⚠️ 确保 `.cdn/cn/EntityLists/` 下**同时存在**
`PathFile` 和 `10939-android_medium.csv` 两个文件(内容一致,缺一个会按端点不同随机 404,复制改名即可)。

**验证点**:浏览器打开 `http://127.0.0.1:8001/admin` 能看到管理后台 → 服务端 OK。

**设服务器时间(别跳过)**:管理后台首页的时间卡片,把服务器时间设到 **2025-08-04 前后**。
表里的活动排期集中在 2023-11~2025-10,时间在窗外时活动页会**静默空白**(零报错)。
深渊连战 700099 是永续排期不受影响——"Rush 页能看到 700099 但活动页空白"就是时间没设的实锤。

> 自制内容的数据**随代码已经到手**,不用额外下载:服务端层在 `assets/*.json`,
> 客户端层已打包成 `assets/asset-patch/active/` 里的增量链(git 跟踪,服务端自动下发),
> 链尾 **1.4.312**（本文写作时；现以 `assets/asset-patch/manifest.json` 末条为准）= 两模式 + 15 武器 + 八位自制/改造角色终态；新增内容含光暗龙、拉芙、基诺维的主数据、技能、立绘、像素、特效与语音。
> 链起点 **1.4.54**(官方 dump 链尾),桥接边随仓自带,不需要额外索要。

## 2. 把完整客户端基座指向你自己的服务器

### 推荐路线:只换地址,不要自己漏打 P-code

下载上表唯一推荐的 `WorldFlipper-abyss-v2.apk`。它已经包含五层客户端补丁:

1. 免登录;
2. 私服重定向落点;
3. 深渊装备战斗门控;
4. 赛瑞斯双形态 P-code;
5. **通用逐角色像素缩放 P-code**(包含队伍格 `CharacterCell` 修复)。

第 5 层不是某一个角色的图片包,而是让渲染器尊重角色资源里的 `frame.scale`。漏掉它时,
杰拉德、基诺维等使用非官方原始尺寸的像素会被强制放大;因此**不要拿旧 APK、官方 APK,
也不要只打“免登录 + 重定向”就发给玩家**。

先核对基座,两项必须同时一致:

```text
文件名: WorldFlipper-abyss-v2.apk
大小:   139714293 字节
SHA256: 9b539c210a80d76856ddbdf67e426746c020e9b389f78a63771a750327608772
```

PowerShell 校验:

```powershell
(Get-FileHash .\WorldFlipper-abyss-v2.apk -Algorithm SHA256).Hash.ToLower()
python -X utf8 client-patch/repoint-apk/verify_apk_host.py .\WorldFlipper-abyss-v2.apk
```

这个基座里的地址是构建者的私有地址,**不能直接当成你的服客户端发出去**。照
[`client-patch/repoint-apk/给服主的重指向指南.md`](../client-patch/repoint-apk/给服主的重指向指南.md)
生成并备份你自己的 keystore,再运行 `repoint_build.py`;它只替换
`DevConfig_gf_android` 的一个 `IPv4:端口`,五层补丁字节保持不变,并在成品旁写
`.build-report.json`。快速工具当前只接受 **IPv4:端口 + 明文 HTTP**;需要域名/HTTPS 时走下方高级路线。

发包前必须完成三项回读:

```powershell
# <旧地址> 从 .build-report.json 的 host_old 复制;不要把私有地址写进公开说明
python -X utf8 client-patch/repoint-apk/verify_apk_host.py `
  .\WorldFlipper-myserver.apk --expect 你的IPv4:端口 --forbid <旧地址>
apksigner verify --verbose --print-certs .\WorldFlipper-myserver.apk
```

- `.build-report.json` 的 `schema_version` 必须是 `2`,`checks` 五项齐全:
  `sdkDummy`、`host_swap`、`render:pixel-art`、`render:member-view`、`render:character-cell`,
  且 `render_sites_before` 与 `render_sites_after` 逐字段相同(schema 1 的报告没验过第三个渲染落点);
- `verify_apk_host.py` 必须输出“全部断言通过”;
- 启动客户端后,你的服务端日志必须实际出现版本检查/登录请求。

同一把 keystore 签出的后续 APK 可以覆盖安装并保留本地身份;换 keystore 必须卸载重装,
玩家会显示成新号,需要服主在后台重绑原存档。

### 高级路线:从官方 APK 手工重做五层补丁

只有需要域名/HTTPS或修改客户端逻辑时才走这一段。拿官方 APK 里的主 SWF,
用 FFDec 导出 AS3 目录(记为 `EXPORT_DIR`),五层必须全部完成:

```bash
# ① 免登录 + ② 重定向到你的服(改 DevConfig 两处)
bash client-patch/apply.sh <EXPORT_DIR> 192.168.1.10:8001   # 换成你的 IP:端口 或域名

# ③ 深渊装备战斗门控(不打 = 武器装上不生效!)
python -X utf8 client-patch/abyss-mode-equipment/patch.py \
  --source <EXPORT_DIR>/pinball/common/data/character/BattleCharacterLogic.as \
  --output <EXPORT_DIR>/pinball/common/data/character/BattleCharacterLogic.as
```

①-③ 改完用 FFDec 把 AS3 导回 SWF,然后打两个 P-code 层补丁:

```bash
# ④ 赛瑞斯双形态(不打 = 播放他的特殊演出必崩!)
python -X utf8 client-patch/dual-form-v1/build_patch.py \
  --baseline-swf <导回的主SWF> --baseline-pcode-root <FFDec的pcode导出目录> \
  --ffdec-jar <ffdec.jar> --output-dir <空目录> --profile-dir <FFDec配置目录> \
  --manifest client-patch/dual-form-v1/patch-manifest-seris-combat.json

# ⑤ 通用逐角色像素占屏(不打 = 杰拉德/基诺维等像素异常放大)
#    包含 PixelArtCharacterView、MemberView 和 CharacterCell 三个渲染落点
#    完整流程照 client-patch/render-scale-v1/README.md
```

最后:产出的 SWF 替换回 APK → `zipalign` → `apksigner` 重签 → 安装到设备。

**踩坑提示**:

- apksigner 对**中文路径**会失败——APK 和 keystore 先拷到纯英文路径再签。
- 玩家**换新签名的包必须卸载重装**,而卸载会抹掉本地客户端身份,下次登录变新号。
  服主可在管理后台按 `device_id` 把旧存档重绑;或全程用同一个 keystore(可覆盖安装,身份保留)。

## 3. 进游戏,等它自己更新

装好客户端启动游戏,它会向你的服拉增量,从基础 CDN 版本一路爬链到链尾（`assets/asset-patch/manifest.json` 末条，写作时为 1.4.312）。

- 看服务端日志出现 `[CDN] get_path` = 客户端在正常拉更新。
- 更新过程中**别强杀游戏进程**(模拟器上 force-stop 会触发 700MB+ 全量重下)。
- 进到主城即更新完成。

## 4. 发放八位角色(管理后台邮件)

角色不进卡池,由服主邮件发放:

1. 打开 `http://你的服:8001/admin` → **邮件**页。
2. 附件类型选「**角色**」,按需分别发送 `129999`、`139999`、`149998`、`149999`、`151159`、`261089`、`169998`、`169999`(群发全体存档)。
3. 玩家进游戏 → 邮箱领取。

> ⚠️ **前提:玩家客户端已经更新到链尾（写作时 1.4.312，以 manifest.json 末条为准）**(步骤 3 完成)。
> 客户端还没更新就领取新角色,会因缺资产在下载/进战时崩溃。

## 6. 出问题对号入座

| 症状 | 原因 | 解法 |
|---|---|---|
| 活动页/领主战空白,零报错 | 服务器时间在排期窗外 | 管理后台把时间设到 2025-08-04 前后 |
| 打完 15 轮或开兑换商店报 C8601 | 客户端没接上增量链 | base CDN 须完整到 1.4.54;看 `get_path` 是否在下发 1.4.54→1.4.312 |
| 武器装上战斗里没效果 | 客户端缺③号补丁 | 重打客户端,五个补丁齐 |
| 赛瑞斯特殊演出一放就崩 | 缺④号补丁 | 同上 |
| 杰拉德/基诺维等像素明显偏大 | 下了旧 APK,或漏了⑤号通用像素 P-code | 换上面 SHA256 对应的五合一基座,重新重指向并重签 |
| 领取自制角色后崩溃 | 客户端没更新到链尾就发了角色 | 先让全员更新到链尾（写作时 1.4.312）,再发邮件 |
| 客户端卡加载/资源 404 | 基础 CDN 没放对/PathFile 缺一份 | 步骤 1 的 CDN 检查两条 |
| 玩家换包后变新号 | 新签名 → 卸载重装抹身份 | 管理后台按 device_id 重绑存档 |
| 卡在别的版本接不上链 | 客户端经别的 CDN 血统到了链外 | 见 [self-host-modes.md](self-host-modes.md) 的「通用桥接」章节 |

还修不好:复现一次,把服务端 `logs/http404.log` 新增的 404 路径带上,到仓库提 issue。
