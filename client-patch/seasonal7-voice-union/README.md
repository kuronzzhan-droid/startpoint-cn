# 七角色固定槽语音随机候选

这是可选的客户端扩展源码，尚未安装。普通多语音合并并不需要本补丁。

## 原生支持范围

- 技能发动、开战、强力弹射、掉落、胜利：原生按连续编号发现语音候选。
- 主页台词：原生从 `character_speech` 收集符合解锁条件的多条台词。
- 技能准备：原生分别读取 `battle/skill_ready`、`battle/matched_skill_ready` 单一路径。
- 加入：原生取第一条加入台词。
- 觉醒：原生取当前觉醒等级的第一条匹配台词；支持多个觉醒等级不等于同等级随机多条。

因此两版录音全部保存并不需要 APK 改动；只有准备、加入、同等级觉醒也要求每次随机两版时，才需要这里的额外路由。

## 范围

仅七角色 ID：139994、139993、159998、159997、159996、169992、129991。
仅插入四个方法：准备播放处、准备音频预加载、加入台词选取、觉醒台词选取。
普通准备/条件匹配准备的原有判定保留；加入和觉醒同时选择整条字幕及其音频。
资源缺失、只有单条台词或非目标角色时，回退原生行为。

源码锁定已核实的设备 SWF 哈希，并验证四个方法哈希。输入不符时拒绝执行，不能直接用于另一版客户端。
构建不写 APK、不安装、不写角色工作包、live store 或 CDN。

## 构建与检查

```powershell
python client-patch/seasonal7-voice-union/patch.py ORIGINAL.swf CANDIDATE.swf --report REPORT.json
python -m unittest discover -s client-patch/seasonal7-voice-union -p 'test_*.py' -v
```

补丁检查原有指令可逆恢复、其他方法不变、栈/作用域、SWF 序列化回读。
测试以受控随机数执行注入指令，验证两版可达、固定槽条件、字幕对应及原生回退。
这些是静态和模拟证据，不能代替游戏实机触发验证。

音频合并工具：`mod-tools/wf_seasonal7_voice_merge.py`。
其输出包含两边原始音频哈希、无损标准音频与游戏存储编码、连续槽号、字幕键级修改清单和试听页。
`requires_client_patch` 只标记新增固定槽的第二版；原生槽第一版正常可播。
