# v35 客户端补丁（112–143）

测试服客户端 v35a–v35k 新增的补丁源码。v35k（APK versionCode 1008009）是测试服当前在用的版本。

- `112`–`143`：每个补丁一个目录，结构同 `111`：README、pcode（改前/改后）、source。
- `runN-README.md`：每一轮的说明，列出这一轮加了哪几号补丁和对应的 capability。
- `run11-source/`：最后一轮（v35k）的构建与验证脚本。它在 v35j SWF 上叠加 141–143。

| 轮次 | 补丁号 | 内容 |
|---|---|---|
| run1 | 112–119 | WFX 效果查询、直击倍率/合并、充能上限、能力抗性、PF 连击快照、PF Lv4 数据化、Fever 道具通用 |
| run2 | 120–124 | 队长技解锁、自适应属性、溢出治疗转伤害、能力特效、直击倍率钳制 |
| run3 | 125–129 | 超级 Fever、Fever 语音、技能准备语音轮换通用、双形态 UID、装备规则数据 |
| run4 | 130 | 直击按目标固有状态 |
| run5 | 131 | WFX 隐藏状态不显示图标 |
| run6 | 132–134 | 治疗转伤害、治疗加 Fever、解锁 v2 |
| run7 | 135 | 首位空队伍取队长的守卫（修 C2330） |
| run8 | 136 | 全程超限与窗口守卫 |
| run9 | 137 | 解锁只放开主位自身合击 |
| run10 | 138–140 | 角色身份标签、按施放者最大 HP 的护盾、合击队长技显示 |
| run11 | 141–143 | 按目标弱体数加直击次数、任意来源治疗转伤害（带 CT）、任意来源治疗加 Fever |

数据写法速查见 startpoint-cn-mod-tools 的 `docs/客户端补丁效果码速查.md`。

构建需要本机的 v29-coop 底包，用环境变量 `WF_BASE_APK` 指定路径。APK 本体、签名证书和测试服准入参数不在仓库里。
