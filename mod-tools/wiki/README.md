# MOD 角色 Wiki

独立、只读、可离线使用的角色资料站。前端无依赖，生成数据和媒体不进版本控制。

## 导出与打开

在仓库根目录执行（Python 环境需有 Pillow，复用现有 MOD 工具依赖）：

```powershell
python -X utf8 mod-tools/wf_wiki.py --output D:/WF/out/MOD角色Wiki/site
```

双击输出目录的 `index.html` 或 `打开角色Wiki.bat`。复制或压缩整个输出目录后仍可离线浏览。
更改游戏数据后再次执行导出命令，再刷新页面。不要只复制 HTML；图片、语音、数据和脚本必须一起保留。

可选本机 HTTP 预览（只绑定本机，不改游戏服务端）：

```powershell
python -m http.server 8877 --bind 127.0.0.1 --directory D:/WF/out/MOD角色Wiki/site
```

然后打开 `http://127.0.0.1:8877/`。这是本地预览，不会获得互联网访问地址。

## 资料口径

- 以当前 profile 的 store 和官方归档作对比：收录新增角色，以及资料、数值、能力、技能表或直接引用的主技能程序发生变化的官方角色。
- 分为毛茸异世界、原创与改版、Boss角色、小动物四栏，保留全局搜索。毛茸异世界收录赛瑞斯、杰拉德、基诺维、凯尔；赛瑞斯另标“早期方案，后续将重做”。小动物沿用项目十五角色名单并加海豹球，Boss按可玩化来源登记；分类清单集中在 `wf_wiki_categories.py`，不按名字猜测。
- 页面显示导出版本与时间，属于静态快照。存在 pending 或导出时来源发生变化会拒绝完成，避免混入在途版本。
- 技能的 1/2 表层级表示普通/进化，不是技能等级；技能能量显示满级值，保留初级值。
- 能力优先显示自定义面板说明，同时保留逐行自动解析和原始数据。自动解析及技能程序摘要不代表实际对局验收。
- 立绘解码后缩放为 WebP 保留透明度；语音只解码当前存储资源，不生成新音频。相同内容去重保存。
- 中文字幕优先取当前游戏台词表，标记为游戏内字幕；台词稿需与当前音频哈希匹配才引用。原版音频仅有 ID3 标签差异时可核对完整音频帧哈希。未找到可靠原文/翻译时明确标注，不能按槽名硬套旧稿。

## 维护边界

`wf_wiki.py` 负责导出入口；`wf_wiki_catalog*` 负责角色资料；`wf_wiki_voice*` 负责语音字幕；
`wf_wiki_media.py` 负责媒体解码；本目录保存前端源码。此工具不修改 store、pending、角色候选或旧后台，不发布游戏数据。

聚焦检查：

```powershell
python -X utf8 -m unittest discover -s mod-tools/tests -p 'test_wiki*.py' -v
```
